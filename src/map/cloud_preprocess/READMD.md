# 3d点云处理

## 功能实现

### ros2 接口

1. 接收3d点云,imu数据（mid360的livox_ros_driver2），odom定位

2. 输出处理好的3d点云（障碍物和过滤的点云，2个话题）


### 功能

1. 点云去畸变（可选）

2. 离群点滤波

3. 处理3d点云 
去除坡度，地面，保留墙壁等障碍物，针对地面机器人
可行性分析

思路： 1.法线聚类，过滤低梯度的点云
      2. 高程分析，保留邻近梯度变换大的点云，对每个珊格中z值高的保留

4. tbb并行处理（可选）


### 要求

1. 代码风格简洁

2. 接口设计完善

3. 注释完善

4. 记录每次更改(PARAM_GUIDE,md)

5. 模块分离（ros2, cloud_proprocess）

6. 代码用尽量少的代码完成功能设计

7. 尽量使用pcl,spdlog,tbb等实现算法
