# RMUC2027 高地台板立面缺口修补 改造记录

## User Intent

MA_Nav 建图时，台阶旁高地上出现消不掉的障碍。经 rosbag 分析，确认原因是仿真网格有缺口，激光从缺口打到了高地下方的地面。修补网格。

## Scope

- `pb_rm_simulation/meshes/RMUC2027_world/meshes/rmuc_2027.stl`

## Explorer Findings

- 高地台板在网格自身坐标中位于 x ∈ [-2.2108, -1.0625]，即 odom 坐标（出生点 3.21, 9.6）下的 x 4.60 到 5.75。它是一块厚 0.15 m 的板，板底比低地地面高 0.05 m。
- **前沿立面缺口**：y≈-1.123，z 从 1.5759 到 1.6259，没有面，形成一条 5 cm 高的敞口缝。低地上的激光（俯角约 -5°）从这里射入，扫到高地下方的地面（odom z≈-0.13）。
- **西侧面缺口**：x=-2.2108 一侧，台面西沿和板底之间没有面，有 7 条开放边，总长约 2 m。高地上的激光从侧面射入，扫到台面下方。
- 用 rosbag `rosbag2_2026_10_23-16_26_25` 做离线射线复核：落到台面下方的点共 1434 个，原网格只能挡住 189 条射线。
