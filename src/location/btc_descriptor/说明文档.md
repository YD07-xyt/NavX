# BTC 说明文档

**BTC（Binary Triangle Combined Descriptor）** 是一种用于 3D 地点识别（Place Recognition / 回环检测）的全局 + 局部组合描述子。它面向大规模非结构化环境（室内外、无特征场景），并在 SLAM 系统中作为回环模块使用。

核心思想：

- **全局三角描述子（Stable Triangle Descriptor, STD）**：在点云中提取三个关键点组成三角形，以三条边长作为描述子。边长在视角 / 朝向变化下保持不变，因此天然具备视角无关性（viewpoint invariance）。
- **局部二值描述子（Binary Descriptor）**：对三角形每个顶点（关键点），将其局部几何结构编码为一个二值直方图，用于增强区分度与描述能力。

两者组合即为 BTC，既保持视角无关又具备强判别力。

## 1. 系统架构

### 1.1 整体流程

```
                ┌──────────────── 单帧点云 (submap) ────────────────┐
                │   pcl::PointCloud<pcl::PointXYZI>                 │
                ▼                                                   │
   ┌─────────────────────────────── BtcDescManager ───────────────────────────┐
   │                                                                          │
   │  1) init_voxel_map        体素化 + 八叉树建图                           │
   │  2) get_plane             每个体素做主成分分析(PCA)提取平面            │
   │  3) get_project_plane     平面合并(法向/距离一致性)                    │
   │  4) binary_extractor      向参考平面投影 -> 二值描述子(角点)          │
   │  5) generate_btc          对候选角点建三角形 -> BTC 描述子            │
   │  6) candidate_selector    在数据库哈希表中粗匹配, 投票选候选帧        │
```

## 2. 算法详解

### 2.1 平面提取（全局结构）

1. **体素化**：按 `voxel_size` 将点云分桶（`init_voxel_map`），每个体素内点超过 `voxel_init_num` 才参与。
2. **PCA 平面检测**：对体素内点计算协方差矩阵，求最小特征值对应的特征向量作为法向。若最小特征值 `< plane_detection_thre`，判定为平面（`init_plane`，`src/btc.cpp:125`）。
3. **平面合并**：将法向相近（`< plane_merge_normal_thre`）且到彼此平面距离均 `< plane_merge_dis_thre` 的平面合并，更新中心/法向/协方差（`merge_plane`）。合并后的大平面作为投影参考面。

### 2.2 二值局部描述子（Binary Descriptor）

对前 `proj_plane_num` 个最大平面，执行 `extract_binary`：

1. 以平面法向建立局部坐标系（x/y 轴）。
2. 在 ±`proj_dis_min/max` 范围内的点投影到该平面，得到 2D 图像网格（分辨率 `proj_image_resolution`）。
3. 将每个点沿法向按 `proj_image_high_inc` 切片，统计每层是否有点，形成**二值占用直方图** `occupy_array_`（局部几何结构编码）。
4. 以 5×5 网格分块取每个 block 的最大占用作为候选角点，若 `line_filter_enable` 则剔除线状点。
5. 对候选角点做**非极大值抑制（NMS）**：半径 `non_max_suppression_radius` 内只保留 `summary_` 最大的点，最终取前 `useful_corner_num` 个作为关键点（角点）。

### 2.3 全局三角描述子（BTC）

`generate_btc`：

1. 对所有角点构建 K-D Tree，对每个点取 K=`descriptor_near_num` 个近邻。
2. 任取两近邻与自身组成三角形，三条边长需落在 `[descriptor_min_len, descriptor_max_len]` 内，且非退化（`c-b-a > 0.2` 近似共线剔除）。
3. 将三边升序排列后乘以 `triangle_resolution` 缩放，得到 `triangle_`（描述子主体）。
4. 三角形三个顶点分别携带各自的二值描述子 `binary_A/B/C_`，构成完整 BTC。

> **视角无关性**来源：三角形三边长度在刚体变换（任意旋转平移）下恒定，因此 BTC 对传感器位姿不敏感。

### 2.4 回环检索与验证

**粗匹配（candidate_selector）**
- 对当前帧每个 BTC，在哈希表中检索三边长度相近（距离阈值 `rough_dis_threshold * ||triangle||`，并在 3×3×3 邻域 voxel 内）的数据库条目。
- 计算 BTC 相似度（三组二值描述子相似度均值 `binary_similarity` 超过 `similarity_threshold`）。
- 按候选帧 ID 投票，取票数最高的前 `candidate_num` 帧作为候选。

**几何验证（candidate_verify）**
- 对每个候选，用 `triangle_solver` 通过三对顶点 SVD 解算相对位姿（Kabsch 算法，`src/btc.cpp:1809`）。
- 将所有匹配对顶点变换后，统计重投影距离 `< 3m` 的投票数；票数 `>= 4` 视为有效。
- 用 `plane_geometric_verify` 做平面-to-平面几何验证：将源平面云用位姿变换后，对目标平面云做 KNN，统计法向一致且点到面距离 `< dis_threshold` 的匹配比例作为 `verify_score`。
- 若 `verify_score > icp_threshold`，则触发回环，返回最佳候选帧 id、`relative_pose(SE3)`、匹配对列表。

### 2.5 时间复杂度

- 描述子提取：体素化 + 平面为 O(N)，角点 KNN 与三角组合为 O(M·K²)（M 为角点数）。
- 检索：哈希表邻域查询近似 O(1)/描述子，整体远快于暴力匹配。
- 节点自带计时（`descriptor_time` / `querying_time` / `update_time`），运行结束打印均值。

## 3. 输入输出

### 3.1 输入

| 输入 | 形式 | 说明 |
|------|------|------|
| 点云序列 | `.bin` 或 `.pcd` | 子地图（submap）累积点云，命名 `000000.bin`、`000001.bin` …（6 位补零） |
| 位姿文件 | `pose.txt` | `Submap_id pos_x pos_y pos_z quat_x quat_y quat_z quat_w`，仅用于可视化与 GT 重叠率评估 |
| 配置 | YAML | 见 `config/config_outdoor.yaml` / `config_indoor.yaml` |

- `.bin` 格式：每个点 4 个 `float`（x, y, z, intensity），小端二进制，由 `read_lidar_data` 读取（`example/place_recognition.cpp:13`）。
- 节点参数（`launch/place_recognition.launch.py`）：
  - `setting_path`：配置文件路径
  - `pcds_dir`：点云目录
  - `pose_file`：位姿文件路径
  - `read_bin`：true 读 bin，false 读 pcd
  - `cloud_overlap_thr`：判定真阳性所需的 GT 重叠率（默认 0.5）

### 3.2 输出

| 输出 | 类型 | Topic / 含义 |
|------|------|--------------|
| 回环结果 | `pair<int,double>` | `(-1,0)` 表示无回环；否则为 `(候选帧id, 验证分数)` |
| 相对位姿 | `pair<Vector3d, Matrix3d>` | 当前帧到匹配帧的 `t + R` |
| 匹配对 | `vector<pair<BTC,BTC>>` | 用于可视化的三角描述子匹配 |
| `/loop_status` | `MarkerArray` | 绿线=真阳性回环，红线=假阳性，白线=轨迹 |
| `/cloud_current` / `/cloud_matched` | `PointCloud2` | 当前/匹配子地图点云 |
| `/cloud_key_points` / `/cloud_matched_key_points` | `PointCloud2` | 关键点（角点） |
| `descriptor_line` | `MarkerArray` | 三角描述子连线 |
| 终端统计 | 文本 | 子地图总数、触发/真实回环数、各阶段平均耗时(ms) |

## 4. 部署（编译与运行）

### 4.1 环境依赖

- **ROS**（Kinetic / Melodic / Noetic 等，需 `roscpp`、`pcl_ros`、`cv_bridge`、`tf_conversions`）
- **PCL**（点云库，`libpcl-all-dev`）
- **OpenCV**（配置读取依赖 `cv::FileStorage`）
- **Ceres Solver**（平面 ICP 非线性优化，CMake 中 `find_package(Ceres REQUIRED)`）
- **GTSAM**（CMake 中声明依赖，当前示例未直接调用）
- **TBB**（并行，`target_link_libraries` 含 `tbb`）
- C++17（`CMakeLists.txt:8`）

建议 Ubuntu 18.04/20.04 + ROS Melodic/Noetic，PCL 1.8/1.10，Ceres 1.14+，OpenCV 3/4。

### 4.2 编译

将本包放入 catkin 工作区 `src/` 下，例如：

```bash
cd ~/catkin_ws/src
# 将 btc_descriptor 包放到此处
cd ~/catkin_ws
catkin_make -DCATKIN_WHITELIST_PACKAGES="btc_desc"
# 或
catkin build btc_desc
source devel/setup.bash
```

生成可执行文件 `btc_place_recognition`。

### 4.3 运行（地点识别示例）

```bash
ros2 launch btc_desc place_recognition.launch.py
```

启动前请按需修改 `launch/place_recognition.launch.py` 中的路径：

```xml
<param name="setting_path" value = "$(find btc_desc)/config/config_outdoor.yaml"/>
<param name="pcds_dir"     value = "/path/to/velodyne"/>     <!-- 存放 000000.bin 等 -->
<param name="pose_file"    value = "/path/to/pose.txt"/>      <!-- Submap_id x y z qx qy qz qw -->
<param name="read_bin"     value = "true"/>
<param name="cloud_overlap_thr" value = "0.5"/>
```

运行后自动打开 RViz（`rviz_cfg/loop.rviz`）可视化。终端会按帧打印描述子提取 / 查询 / 建库耗时，结束时打印总体统计。

> KITTI 示例位姿见 `poses/kitti00~08.txt`，可直接套用其格式。

## 5. 参数调优（调参指南）

配置文件位于 `config/`：室外 `config_outdoor.yaml`，室内 `config_indoor.yaml`。所有参数在 `ConfigSetting`（`include/btc.h:28`）定义，由 `load_config_setting` 加载。

### 5.1 二值描述子参数

| 参数 | 室外默认 | 室内默认 | 作用与调优建议 |
|------|------|------|------|
| `useful_corner_num` | 500 | 500 | 每帧最大角点数。场景越大、结构越丰富可适当增大；过小会漏特征 |
| `plane_detection_thre` | 0.01 | 0.01 | 体素协方差最小特征值阈值，低于则判为平面。噪声大时调大 |
| `plane_merge_normal_thre` | 0.1 | 0.1 | 平面合并法向容差。室内多平行面可略放宽 |
| `plane_merge_dis_thre` | 0.3 | 0.3 | 平面合并距离容差 |
| `voxel_size` | 2.0 | 0.5 | 体素边长。**室外大场景用大值(2~5)控计算量，室内用小值(0.3~0.5)保精度** |
| `voxel_init_num` | 10 | 10 | 体素最少点数，低于则跳过 |
| `proj_plane_num` | 1 | 2 | 参与投影的参考平面数。室内结构单一建议 2 |
| `proj_image_resolution` | 0.5 | 0.2 | 投影网格分辨率(米)。**室内减小到 0.1~0.2 提精度，室外增大提速** |
| `proj_image_high_inc` | 0.1 | 0.1 | 法向切片高度增量(米)，决定二值直方图维数 |
| `proj_dis_min/max` | -1 / 4 | -1 / 4 | 参与投影的点到平面距离范围(米) |
| `summary_min_thre` | 10 | 6 | 单网格最少点数，过滤噪声角点。室内点稀疏可降 |
| `line_filter_enable` | 1 | 0 | 是否剔除线状点。**结构化室外场景(含大量线特征)置 1 提速；室内/无特征场景置 0 否则漏特征** |

### 5.2 三角描述子参数

| 参数 | 室外默认 | 室内默认 | 作用与调优建议 |
|------|------|------|------|
| `descriptor_near_num` | 10 | 15 | 角点近邻数，决定三角形候选量。点密可增大 |
| `descriptor_min_len` | 2 | 1 | 三角形最短边长下限(米)。室内小尺度调小 |
| `descriptor_max_len` | 50 | 30 | 三角形最长边长上限(米)。室外大场景可增大 |
| `max_constrait_dis` | 2 | 1 | 非极大值抑制半径(米)。角点密集时增大以去重 |
| `triangle_resolution` | 0.2 | 0.2 | 边长缩放系数，用于哈希量化精度 |

### 5.3 候选检索参数

| 参数 | 默认 | 作用与调优建议 |
|------|------|------|
| `skip_near_num` | 100 | **跳过邻近帧数。同机器回环置正数(如100)；跨会话/多地图回环置负大数(如 -1000000)** |
| `candidate_num` | 50 | 最大候选帧数，影响召回与耗时 |
| `similarity_threshold` | 0.7 | BTC 二值相似度阈值，过低易误匹配 |
| `rough_dis_threshold` | 0.01 | 三边长度粗匹配距离系数，越小越严格 |
| `normal_threshold` | 0.2 | 平面 ICP / 几何验证的法向容差 |
| `dis_threshold` | 0.5 | 平面验证点到面距离阈值(米) |
| `icp_threshold` | 0.2 | **触发回环所需的最终验证分数阈值。调低更敏感(召回↑误检↑)，调高更保守** |

### 5.4 调参思路

1. **先分场景选配置**：室外用 `config_outdoor.yaml`，室内用 `config_indoor.yaml`，基本无需改动即可跑通。
2. **召回不足（漏回环）**：降低 `icp_threshold`、增大 `candidate_num`、放宽 `similarity_threshold`/`rough_dis_threshold`、增大 `useful_corner_num`、减小 `skip_near_num`。
3. **误检过多（假回环）**：提高 `icp_threshold`、收紧 `similarity_threshold`/`rough_dis_threshold`、提高 `summary_min_thre`（过滤弱角点）。
4. **耗时过长**：增大 `voxel_size`、`proj_image_resolution`，开启 `line_filter_enable`，减小 `descriptor_near_num`/`candidate_num`/`useful_corner_num`。
5. **场景尺度变化**：同步调整 `descriptor_min_len/max_len` 与 `voxel_size` 使三角形边长落在合理范围。
