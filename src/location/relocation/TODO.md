# one
1.准备数据

    Map（目标）：通常是由历史帧拼接成的密集点云，或直接使用已有的全局地图。

    Scan（源）：当前传感器帧，需要变换到地图坐标系。

2.下采样 & 滤波（提升速度）

    对 scan 和 map 都进行体素网格降采样，Map 还可以使用更大体素来进一步减少点数。

3.特征提取（仅 SAC-IA 需要）

    计算 scan 和 map 的法线，再计算 FPFH 特征。这一步耗时，但只在粗配准时做一次。

4.SAC-IA 粗配准

    用特征匹配估计出一个近似变换，把 scan 拉近到 map 附近。

5.NDT 精配准

    将 SAC-IA 的结果作为初始位姿，在 NDT 中进一步优化，得到高精度变换。

6.应用变换

    将 scan 点云变换到 map 坐标系的tf发布 ，完成配准。
