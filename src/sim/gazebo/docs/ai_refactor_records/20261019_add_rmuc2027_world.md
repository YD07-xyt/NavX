# 接入 RMUC2027 仿真地图 改造记录

## User Intent

将新增的 RMUC2027 地图网格接入 Gazebo 仿真，参考已有地图的加载方式。

## Scope

- `pb_rm_simulation` 的 meshes / world / launch。

## Out of Scope

- 雷达外参、雷达发布频率（仅解答，未修改）。
- 默认地图（`world` 默认值仍为 `RMUC`）。
- 其他已有地图配置。

## Explorer Findings

### Files inspected

- `pb_rm_simulation/launch/rm_simulation.launch.py`
- `pb_rm_simulation/world/RMUC2024_world/RMUC2024_world.world`
- `pb_rm_simulation/package.xml`（`gazebo_model_path=${prefix}/meshes`）
- `pb_rm_simulation/CMakeLists.txt`（安装 meshes / world / launch）
- `meshes/RMUC2027_wrold/meshes/rmuc_2027.stl`

### Active logic path

`world:=<名称>` → `LaunchConfigurationEquals` 选中 GroupAction → gzserver 加载 `share/.../world/<world_path>`，并在配置的 x/y/z/yaw 处 spawn 机器人。world 文件中的 `model://` 解析自 `share/pb_rm_simulation/meshes`。

### Data flow

STL 网格 → world 中 map 模型的 collision/visual → Gazebo 物理与雷达射线。

### Risk notes

- 原文件夹名拼写为 `RMUC2027_wrold`，与 `model://` 命名不一致。
- STL 权限为 600。
- 网格为二进制 STL（378666 个面），坐标范围 x 0.15~28.15、y 0.06~16.07、z 0.02~3.82，原点在场地角，与 RMUC2024 坐标系一致。
- RMUC2024 的出生点 (6.35, 7.6) 在 2027 网格中位于约 0.47 m 的凸起上。

### Recommended modification boundary

只新增地图选项，不改动已有地图的配置和默认值。

## Modifier Changes

### Files changed

- 重命名：`meshes/RMUC2027_wrold` → `meshes/RMUC2027_world`；`rmuc_2027.stl` 权限改为 644。
- 新增：`world/RMUC2027_world/RMUC2027_world.world`（以 RMUC2024 world 为模板，网格 URI 指向 `model://RMUC2027_world/meshes/rmuc_2027.stl`，删除了旧的 `<state>` 快照）。
- 修改：`launch/rm_simulation.launch.py`：新增 `WorldType.RMUC2027` 及其配置（x=6.35, y=6.6, z=0.4, yaw=0）、对应 GroupAction，并更新 `world` 参数的描述文本。

### Key changes

可通过 `world:=RMUC2027` 选择新地图。

### Behavior preserved

已有的 RMUC / RMUL / RMUL2026H 配置以及默认 world 均未改变。

### Behavior intentionally adjusted

无。

### Notes

出生点依据网格表面高度采样：(6.35, 6.6) 附近是约 0.26 m 的平整区域，因此 z 取 0.4。尚未在 Gazebo 中实际验证。

追加修改（用户要求）：出生点沿 x 负方向移 3.14 m、沿 y 正方向移 3.00 m，改为 (3.21, 9.6)，z 仍为 0.4。采样确认该点周围 ±0.2 m 内地面高度约为 0.29 m，表面平整。
